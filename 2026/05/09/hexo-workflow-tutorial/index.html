終極自動化 Hexo 工作流：GitHub Actions + Vercel 部署全攻略

发表于 2026-05-09 分类于 技術筆記

在建立個人部落格時，如何實現「寫完即發布」的無感體驗？本文將詳細介紹一套專業的靜態網站架構：透過 GitHub 私有倉庫 存放原始碼，利用 GitHub Actions 自動構建，並最終經由 Vercel 全球加速分發。

🛠 架構概覽

這套工作流的核心在於「職責分離」與「自動化」：

  1. Source Repo (建議私有): 存放 Hexo 源文件（Markdown、主題配置）。
  2. GitHub Actions: 當源代碼有變動時，自動執行 Hexo 構建。
  3. Static Repo (公開): 存放生成後的 HTML 靜態檔案，並開啟 GitHub Pages 功能。
  4. Vercel: 監控 Static Repo，負責邊緣加速與自定義域名綁定。

🌐 第一步：建立 GitHub Pages 靜態倉庫

GitHub Pages 是存放靜態網頁的最佳場所。

  1. 新建倉庫：在 GitHub 上建立一個新的公開倉庫（例如命名為 my-blog-output）。
  2. 開啟功能：
    • 進入該倉庫的 Settings -> Pages。
    • 在 Build and deployment 下，確保 Source 選擇為 Deploy from a branch。
    • Branch 選擇 main (或 master)，目錄選 / (root)。
  3. 完成：此時 GitHub 會為你分配一個 https://<username>.github.io/<repo>/ 的網址。

📝 第二步：配置 GitHub Actions 自動化

在你的 源代碼倉庫 中建立 .github/workflows/deploy.yml，實現自動化構建。

關鍵安全提示：

  • DEPLOY_TOKEN: 請在 GitHub Settings 生成一個 Personal Access Token (PAT)，勾選 repo 權限。
  • 將 Token 填入源代碼倉庫的 Settings -> Secrets and variables -> Actions 中。

⚡️ 第三步：Vercel 加速與域名綁定

為了獲得更好的訪問速度（特別是在國內）和自定義域名：

  1. 導入 Vercel：登入 Vercel 並連結你的 GitHub 帳號，導入上述的 靜態倉庫。
  2. 設定域名：在 Vercel 的專案設定中加入你的域名（如 example.com）。
  3. 自動同步：每當 GitHub Actions 推送新內容到靜態倉庫，Vercel 會自動感應並完成邊緣部署。
